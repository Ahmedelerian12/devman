# Cloud Cheat Sheet

## Goal

Design cloud systems around identity, networking, compute, data, cost, and
recovery.

## Steps

1. Write the workload goal.
2. Pick compute: VM, container, serverless, or managed service.
3. Define network entry points and private paths.
4. Define IAM roles and least privilege.
5. Define backups, logs, metrics, and cost guardrails.
6. Capture tradeoffs in `cloud-design.md`

## Done Looks Like

The design explains why each managed service exists and how it fails safely.
