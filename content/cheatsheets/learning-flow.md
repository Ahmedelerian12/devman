# DevMan Learning Flow Cheat Sheet

Use this loop whenever you feel lost.

## The Loop

1. See the map: `devman learn roadmap`
2. Resume: `devman learn start`
3. Open a short guide: `devman learn cheatsheet <module>`
4. Create files: `devman learn lab <module>`
5. Enter the lab: `cd devman-lab-<module>`
6. Follow the README and cheat sheet commands.
7. Validate from inside the lab: `devman learn validate <module> .`
8. Quiz yourself: `devman learn quiz <module> 5`
9. Finish it: `devman learn complete <module>`
10. Check progress: `devman learn progress`

## When You Are Confused

- Run `pwd` to see where you are.
- Run `ls` to see what files exist.
- Run `cat README.md` inside a lab.
- Run `devman learn cheatsheet current`.
- Run `devman learn activity` to see what you did recently.

## Rule

Do not memorize everything. Build one artifact, validate it, explain it in notes,
then move to the next mission.
